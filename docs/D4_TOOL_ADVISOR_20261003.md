# D4 AI 품질도구 추천 (2026-10-03)

## 목적

이슈가 생겼을 때 어떤 품질도구를 어떤 순서로 써야 할지 모르는 문제를 줄인다. AI는 도구와 순서, 이유를 **제안**만 하고, 적용과 작성은 사람이 한다.

## 동작

1. D4 화면 맨 위 **AI에게 도구 추천받기**를 누른다. 화면의 작성 내용을 먼저 중앙에 저장한다.
2. 서버가 중앙에 저장된 Case에서 기록된 사실만 모아 외부 AI에 보낸다. 순서는 Gemini, 실패하면 Groq.
   - 보내는 것: 고객사·제품·품번·Lot·불량 현상·발생 위치·수량·위험 신호, D2 5W2H·문제 정의문, D2 IS/IS NOT 중 **사실 확인된 행만**, D3 영향 범위, 첨부 파일 이름·유형.
   - 보내지 않는 것: D4 원인 문장, 확인되지 않은 비교행, 첨부 파일 본문.
   - 회사 기본 사실(자체 제조라인 없음, TechL·WinPAC·CTST 외주)을 함께 준다.
3. 응답을 검증한다. 도구 목록에 없는 id·중복은 버리고, 필수 5개 외 추가 도구는 최대 4개, 빠진 필수 도구는 "AI가 설명하지 않은 필수 도구"로 채운다. Case 특성 값이 선택지 밖이면 기본값으로 둔다. 설명 속 영문 코드값은 화면 이름으로 바꾼다.
4. 화면에 보여 준다.
   - 먼저 확인할 사실
   - AI가 읽은 Case 특성 5개 항목과 각 이유
   - 추천 도구와 순서: 왜 필요한가, 확인할 질문, 필요 자료와 가진 곳, 지금 자료로 시작 가능한지, 다음 단계
   - 이번에는 쓰지 않는 도구와 이유
5. **이 추천을 작업대에 적용**을 누르면 Case 특성과 도구가 작업대에 들어간다. 도구의 가설·Evidence·결과는 빈칸으로 추가되고, 도구 카드 위에 "AI 제안 — 확인할 질문·필요 자료"가 표시된다.

## 지키는 것

- AI는 원인·측정값·판정을 쓰지 않도록 지시받는다. 추천은 Case 결재 내용에 포함되지 않는다(`toolAdvice`는 결재 스냅숏에서 제외).
- 서버는 추천을 Case에 쓰지 않는다. 사람이 적용할 때만 화면에서 Case에 들어간다.
- AI를 쓸 수 없으면 오류로 알리고 추천을 지어내지 않는다. 그때는 기존 **규칙 추천 다시 계산**(5개 항목을 사람이 고르는 점수표)을 쓴다. 이 버튼은 AI가 아니므로 이름을 "규칙 추천"으로 바꿨다.
- 생성마다 감사 로그 `D4_TOOL_ADVICE_GENERATED`(사용 AI, 모델, Case 리비전, 추천 도구)를 남긴다.

## 구현

- `tool_advisor.py`: 도구 목록(화면과 같은 25개), 프롬프트, 응답 검증, `ToolAdvisorMixin`.
- `portal_server.py`: `POST /__api__/qms/ai/d4-tool-advice`, `advise_d4_tools`. AI 호출의 최대 출력 길이를 인자로 받게 했다(기존 기본값 3072 유지, 이 기능은 6000).
- `js/views/d4_tool_advisor.js`: 요청·표시·적용·지우기, 도구 카드의 AI 제안 줄.
- `js/views/workspace.js`: 추천 패널 위치, 규칙 추천 이름 변경. `js/approval.js`: `toolAdvice` 스냅숏 제외.
- 권한: 사내 계정. 외주 계정은 403.

## 검증

- `tests/test_tool_advisor.py` 9건(AI는 모의): 도구 목록 밖·중복·초과 제거, 필수 도구 보충, 잘못된 특성값, 쓸 수 없는 응답 거부, 화면 도구 목록·특성 선택지와 일치, 확인 안 된 비교행·원인 문장을 보내지 않음, 첫 AI 실패 시 두 번째 사용, 둘 다 실패 시 502, 저장된 Case·사실·로그인·사내 계정 요구, 코드값 이름 변환.
- 실제 Gemini로 시험 Case(검증용 값, SMT 후 부팅 불가) 확인: 약 5~7초. 필수 5개 + Physical FA, 검사 Coverage, PFMEA Gap을 추천했고, 유출 의심 "있음"과 생산 형태 "외주"를 이유와 함께 제시했다.
- 첫 시험에서 AI가 자료가 없다는 이유로 추가 도구를 하나도 고르지 않아 지시문을 고쳤다("자료가 없다는 이유로 필요한 도구를 빼지 않는다", 회사 생산 형태 제공).

## 한계

- 추천 품질은 D2 기록 수준에 달려 있다. 불량 현상 한 줄만 있으면 일반적인 추천이 나온다.
- 같은 Case라도 요청할 때마다 결과가 조금씩 다를 수 있다.
- 자료를 가진 곳(부서명)은 AI가 쓰는 일반 표현이며 조직도와 맞춰 보지 않는다.
- 첨부 파일 본문은 읽지 않는다(이름만).
