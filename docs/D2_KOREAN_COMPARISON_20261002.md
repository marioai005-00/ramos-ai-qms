# D2 IS / IS NOT 한국어 생성 — 2026-10-02

사용자가 D2 공식 비교표의 설명이 영어로 나오는 문제를 문의했다. 전용 서버 프롬프트에 한국어 출력 조건이 없고, 브라우저는 배열 형식만 확인해 영어 설명도 그대로 저장하고 있었다.

## 수정

- portal_server.py: D2 비교 분석에 고정 한국어 설명 규칙을 추가했다. 제품명/eMMC/BGA153, 품번·Lot·일시·수량·단위 및 JSON 키는 원문 유지. 호출자가 별도 systemPrompt를 제공해도 작업 전용 규칙을 덧붙인다.
- 구분/IS/IS NOT/차이의 문자열·한국어 포함 여부와 Required 상태를 검사한다. 유효하지 않으면 기존 대체 공급자 재시도 경로를 사용하고 여전히 잘못된 응답이면 schemaValid=false를 전달한다.
- 언어 확인은 설명에 한국어가 포함되는지 확인하는 제한적인 검사이며 번역 의미 전체의 정확성 판정을 대신하지 않는다. 기술 식별자 및 영문 제품명은 정상적으로 포함할 수 있다.
- js/views/workspace.js: 요청에 한국어 설명과 실제 입력 사실 보존 조건 추가. 서버 검증 실패·영문 설명·잘못된 행 수/자료형을 AI 결과로 적용하지 않는다. 실패 시 실제 입력값과 확인 필요 비교행을 사용하고 화면에 입력 기반 초안임을 표시한다.
- 허용 PPM, 정상 비교 검사, PCB 실장 위치, 작업 환경, 설비 교정 상태와 원인을 임의 생성하지 않도록 지시한다. 실제 비교 근거가 없는 IS NOT/차이는 확인 필요로 남긴다. 모델의 모든 의미를 자동 사실 검증한 것은 아니며 사람의 원본 확인을 계속 요구한다.
- 모든 새 행은 aiDraft/verificationStatus=Required, D2 humanConfirmed=false로 저장한다. 기존 사람 확인 비교행은 다음 요청의 자료로 전달할 수 있지만 새 결과는 다시 사람이 확인해야 한다.
- D2 버튼은 한국어 AI 비교 (8개), 한국어 기본 비교 (4개)로 표시. 기존 교체 확인 창에 사실 확인 표시를 해제하고 재검토한다는 내용을 명시했다.
- 기존 운영 영문표나 승인 기록을 자동 번역/덮어쓰기하지 않았다. 작성 중인 내용을 저장하고 새로고침한 뒤 D2의 한국어 생성 버튼으로 다시 작성한다. 실제 생성/내용 교체는 사용자가 실행한다.
